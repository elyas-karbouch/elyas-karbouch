## The Problem

Traditional RAG systems using a single vector database:
- ❌ Hallucinate on numeric facts ($5.2B vs $52M)
- ❌ Confuse similar sections (therapeutic vs overdose dosing)
- ❌ Cannot explain their reasoning (fails GDPR Article 22)
- ❌ Cannot meet EU AI Act transparency requirements (August 2, 2026)

## The Solution

**Verifiable AI Architecture**: Structure-aware ingestion → three-store hybrid storage → intelligent retrieval with full provenance.

```
Document  →  [Docling]  →  [TOON]  →  [VAA Core]  →  [PageIndex]  →  [Compliance]
           Extract      Serialize      3 Stores       Structure      Audit
           Structure    Efficiently    + Query        Aware          + Justify
```

**Core Principle**: *Embed words. Store facts.*
- Narrative → Vector store (semantic similarity)
- Facts → Relational store (exact lookup)
- Relationships → Graph store (traversal)
